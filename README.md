
# Mutual Fund Return Prediction

## 📌 Project Overview
This project focuses on predicting 3-year returns of mutual funds based on various attributes such as Market Cap, Type, Risk, and more. The aim is to identify the key drivers behind higher returns and guide smarter asset allocation decisions using a machine learning approach.

## 🔍 Features
- Data cleaning and exploratory analysis
- Visualizations of return distributions and risk categories
- Machine learning model using Random Forest Regressor
- Feature importance analysis to understand what impacts returns the most

## 📁 Files Included
- `dataset.csv` - Raw mutual fund dataset used in the project
- `Mutual Fund Prediction.ipynb` - Python script or notebook with full code
- `README.md` - Project documentation

## 🛠️ Tools & Libraries
- Python 3.11
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## ▶️ How to Run the Project
1. Clone this repository to your local machine.
2. Ensure all required libraries are installed (`pip install -r requirements.txt` if applicable).
3. Run the script or Jupyter notebook to explore the analysis and model results.

## 📊 Model Evaluation
- **Algorithm Used:** Random Forest Regressor
- **Metrics:** RMSE (Root Mean Squared Error), R² Score
- **Outcome:** Identifies the most influential features affecting 3-year mutual fund returns.

## ✅ Outcome
This model provides a data-driven recommendation for which asset factors (such as type, risk level, or market cap) are more likely to contribute to higher mutual fund performance.
